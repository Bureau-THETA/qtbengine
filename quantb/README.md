# QuanTB

QuanTB is an electronic quantification and early warning system designed to support National Tuberculosis Programs and hospitals in optimizing procurement, ordering, and supply planning for TB treatment.  

## 📁 Folder contains installer for QuanTB descktop application

- **`quantb_installer.jar`** – quick-start installer for immediate software installation.  

## Prerequisites

QuanTB requires Java 17 or later.

We recommend [Eclipse Temurin (Adoptium)](https://adoptium.net/), a free and open-source build of the Java platform (JDK/JRE) maintained by the Eclipse Foundation.  
Any standards-compliant Java distribution (such as Oracle Java, Amazon Corretto, or Azul Zulu) will also work.

To check if Java is already installed on your system, run:

java -version

## Quick Start

Once Java is installed, you can set up QuanTB in a few steps:

1. Download the latest `quantb_installer.jar` from the (https://github.com/Bureau-THETA/qtbengine/blob/main/bin/quantb/quantb_installer.jar) page.  
2. Open a terminal (Command Prompt on Windows, Terminal on macOS/Linux).  
3. Run the installer

After installation run quantb-5.0.0.0.exe for Windows, or QuanTB.command for Mac or Linux
